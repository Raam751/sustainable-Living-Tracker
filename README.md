# SustainHome - Sustainable Living Tracker

## Project Description

SustainHome is a comprehensive application designed to help individuals track their household consumption and carbon footprint. The application allows users to monitor their electricity, water, gas, and waste usage, as well as calculate their carbon emissions from transportation, food, and household activities. Through data visualization and personalized recommendations, SustainHome empowers users to make more environmentally conscious decisions.

## Features

- **Dashboard Overview**: At-a-glance view of key sustainability metrics, recent consumption trends, and carbon footprint breakdown
- **Consumption Tracker**: Log and monitor household utilities (electricity, water, gas, waste) with detailed charts and history
- **Carbon Footprint Calculator**: Track emissions from transportation, food, and household activities
- **Reports & Analysis**: Comprehensive visualizations, sustainability scoring, and personalized recommendations

## Tech Stack

- **React.js** (Functional Components + Hooks)
- **React Router** (for multi-page navigation)
- **React Context API** (for state management)
- **Tailwind CSS** (for styling)
- **Recharts** (for data visualization)
- **React Hook Form** (for form handling and validation)
- **Zod** (for schema validation)
- **Shadcn UI** (for UI components)

## Setup Instructions

1. Clone the repository
2. Install dependencies with `npm install`
3. Start the development server with `npm run dev`
4. Access the application at `http://localhost:8080`

## Project Structure

- `src/components`: Reusable UI components
- `src/context`: Context providers for state management
- `src/pages`: Main application pages/routes
- `src/hooks`: Custom React hooks
- `src/lib`: Utility functions
